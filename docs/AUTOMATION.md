# FORGE5 자동 개발

## 예약형 개발 (외부 API 키 불필요)
- 2026-11-21~23 매일 한국시간 09:17 자동 실행을 목표로 하는 GitHub Actions 정의입니다.
- 사전 정의한 미니게임 1개를 생성하고 npm run check를 실행한 다음 검토 브랜치 및 Draft PR을 생성하도록 설계합니다.
- GitHub의 예약 실행은 부하에 따라 늦어질 수 있습니다. 실제 예약 실행 성공 여부는 Actions 기록으로 확인합니다.
- 자동 병합·운영 사이트 배포는 하지 않습니다.
- GitHub Actions가 Contents 쓰기와 PR 생성 권한을 보유해야 원격 브랜치·PR 생성이 가능합니다.

## AI 자율 코딩
- 실제 모델이 새 코드를 설계하려면 OPENAI_API_KEY Secret, 과금 승인, 별도의 AI 실행 활성화가 필요합니다.
- 해당 값은 설정되지 않았으므로 현재 이 저장소는 AI가 24시간 코드를 새로 만들어 내는 상태가 아닙니다.
- API 키를 채팅이나 공개 파일에 적지 마세요.

## 검증
- 실행: npm run check
- 시뮬레이션: FORGE5_DATE=2026-11-21 npm run autodev:run
- 실제 실행과 예정 상태, 사람 검수와 배포 상태는 구분합니다.
